Introducción

Los sitios web se usan para muchos tipos de propósitos. Puede crear escaparates, lo que permite a una empresa vender productos. Puede proporcionar información sobre una organización, como un folleto digital. O bien, puede desarrollar una aplicación totalmente interactiva. Debido a la flexibilidad y la penetración de los sitios web, puede crear todo tipo de proyectos. El primer lugar para empezar al convertirse en desarrollador web es con lenguaje de marcado de Hipertexto o HTML. Imagine que quiere crear un currículum como publicación pública. Ha decidido crear una página web, que puede compartirse ampliamente. Es una excelente manera de controlar cómo se muestra la información. Pero para empezar a crear la página, debe explorar un poco sobre el desarrollo web. En este módulo, aprenderá los conceptos básicos del desarrollo web. Explorará la terminología y las herramientas más usadas y se incorporará a los tres idiomas principales que se usan para crear una página web.

  1. Al finalizar este módulo, podrá hacer lo siguiente:
  2. Explicar qué es una página web y un sitio web
  3. Resaltar las diferencias entre HTML, CSS y JavaScript
  4. Creación de la primera página web

Descripción de la terminología

Pronto escribirá código para crear una página web.

Al comenzar con una nueva tecnología, hay diferentes términos con los que debe estar familiarizado. Si bien el vocabulario se expande a medida que continúa creciendo como desarrollador web, hay ciertos conceptos básicos que le ayudan a comenzar.

Páginas web y sitios web

Las páginas web, las páginas HTML o simplemente las páginas son similares a una página de un libro electrónico. Son una sola pantalla que muestra información. Puede desplazarse hacia arriba y hacia abajo en la página, pero la página se diseñó para ser una colección de datos similares. Los desarrolladores de software crean páginas en archivos HTML . Un archivo es como un documento que puede crear en un procesador de texto. En lugar de escribir en un idioma como inglés o español, se crean archivos con los idiomas diseñados para sitios web. En el desarrollo web, una página web puede ser un único archivo o el resultado de reunir dos o más archivos. En la sección siguiente, obtendrá información sobre los diferentes archivos que se pueden usar para crear una página web. Un sitio web es un conjunto de páginas. A medida que regresamos a nuestra analogía de libros electrónicos, el propio libro electrónico sería el sitio web. Tiene todas las páginas y la lee un usuario una página a la vez. Un sitio web podría ser una sola página, miles de páginas y todo entre ellos. A medida que lee esta unidad, está leyendo una página web. Desplácese hacia arriba y hacia abajo para examinar la información que desea. Al final, navegará a otra página para revisar la unidad siguiente. Todas estas páginas componen el sitio que es Microsoft Learn.

Crear una página web

Las páginas web se crean principalmente con una combinación de tres lenguajes: lenguaje de marcado de hipertexto (HTML), hojas de estilos en cascada (CSS) y JavaScript. Estos idiomas pueden existir en un solo archivo. Pero se pueden separar en varios archivos. Existen muchos "programas auxiliares" (denominados marcos) para ayudar. Sin embargo, en su núcleo, todos hacen HTML, CSS y JavaScript. Al igual que todos los programas, HTML, CSS y JavaScript solo no pueden hacer mucho (y pueden ser difíciles de leer). Necesitan una herramienta que pueda "leerlas" y saber qué hacer con ellos. El explorador web es un ejemplo de tal herramienta. HTML El código HTML le indica al explorador web lo que tiene que hacer con la información de la página mediante el marcado. El marcado muestra determinadas partes del texto de una manera específica. Algunas partes del texto deben estar en negrita o en cursiva. Algunos texto deben estar en una tabla. Las etiquetas HTML indican al explorador qué hacer. Si desea que el navegador ponga algo en negrita, lo escribiría como esto en HTML: HTML This is bold text Las etiquetas "strong" indican al navegador que el texto en medio debe estar en negrita. Aparecerá como texto en negrita al verlo en un explorador: This is bold text CSS CSS agrega más estilos a la página, como el color para crear algo o qué fuente se va a usar. CSS es eficaz, incluso puede indicar al explorador dónde se debe mostrar la información en la página. JavaScript Por último, JavaScript le permite hacer cosas a los elementos de una página. JavaScript puede indicar al explorador que cree elementos como botones o mostrar la fecha. Pero un script también indica al explorador qué hacer cuando se hace clic en el botón, como enviar datos en un formulario. Importante: Este módulo se centra únicamente en HTML y en un único archivo para una página web. A medida que continúa creciendo como desarrollador, aprenderá a dividir una página en varios archivos y por qué podría decidir hacerlo. - Exploración del código HTML principal El lenguaje de marcado de hipertexto, o HTML, es el lenguaje principal que se usa para crear una página web. HTML se usa para describir la información que se va a mostrar al usuario. HTML indica a un explorador cómo mostrar texto. Nota: La palabra hipertexto procede de tener texto en una página que cuando se hace clic o pulsa lleva al usuario a otra página: vínculos o hipervínculos. Presentación de etiquetas y elementos Cuando da formato al texto como hacer negrita o ampliar la fuente, no siempre piensa en lo que sucede en "en segundo plano". Cuando experimenta texto en una página web, el explorador realiza el trabajo para darle formato mediante código. El código HTML está detrás de lo que se muestra. El código indica al explorador qué hacer para que el texto aparezca como lo hace. Como hemos aprendido en una unidad anterior, cuando una página web tiene texto en negrita, las palabras de código HTML que indican al explorador que haga que el texto en negrita se llamen etiquetas. Las etiquetas rodean el texto que debe mostrarse de forma específica o transformarse. Las etiquetas suelen tener un inicio y un final, con texto entre ellas. Una etiqueta y cualquier contenido entre la apertura y cierre se denomina elemento Esta es la etiqueta de apertura para que un texto se vea en negrita: Esta es la etiqueta de cierre para que un texto se vea en negrita: Este es un elemento: Make me bold Importante: A menudo, los desarrolladores usan los términos etiqueta y elemento de manera intercambiable. Aunque técnicamente significan diferentes cosas, en la mayoría de las conversaciones, la ligera diferencia en el significado no es importante. Los encabezados son elementos comunes que se numeran uno a seis, y uno es la parte superior de la jerarquía y seis es el más bajo. Los encabezados se escriben como h1 a través de h6.
